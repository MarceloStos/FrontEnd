# Contexto do Projeto e do Desenvolvedor

## Perfil
Sou um desenvolvedor focado em backend, com experiência na construção de APIs RESTful robustas e familiaridade com conteinerização (Docker). Este é o meu primeiro projeto focado em frontend (React). 

## Objetivo do Projeto
Este SPA é para divulgar meu trabalho como desenvolvedor, com foco na evolução dos sistemas que construí (Sistema de RH, Sistema de Frota, Sistema de Estoque). Mostrando como interfaces antigas em modo texto ou Java Swing foram modernizadas.

## Regras de Código (Diretrizes para o AntiGravity)
1. **Arquitetura Limpa:** Aplique princípios SOLID e Clean Code no React. Mantenha a separação de responsabilidades: isole a lógica de busca de dados (APIs) da interface visual (componentes).
2. **Estilização Pragmática:** Como meu foco é backend, evite sugerir CSS puro e complexo. Dê preferência a bibliotecas de utilitários como Tailwind CSS para manter o visual profissional com mínimo esforço.
3. **Foco na Informação:** O design deve destacar a arquitetura técnica dos projetos (modelagem de banco de dados, fluxos de API, tecnologias backend usadas).
